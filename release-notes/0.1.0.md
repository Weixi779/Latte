# latte 0.1.0

Latte's first public release provides focused memory and file caching
infrastructure for Swift applications across Apple platforms.

## highlights

### cache contracts

- `Caching` defines synchronous value-or-miss cache behavior.
- `AsyncCaching` provides the corresponding asynchronous, throwing contract.
- Concrete caches own their capacity, expiration, storage, and concurrency
  semantics without exposing a generic policy or backend abstraction.

### memory cache

- `LRUMemoryCache` provides thread-safe LRU caching with configurable cost.
- Insertions support weighted values, multi-entry eviction, resident updates,
  and normal oversized-candidate rejection.
- Removed keys and values are released outside the synchronization boundary,
  allowing safe cache reentry during deinitialization.

### file cache

- `LRUFileCache` provides an awaited, directory-backed `Data` cache.
- Stable key material is hashed with SHA-256 and original keys are never
  persisted.
- Directory ownership markers, complete inventory validation, atomic
  publication, startup reconciliation, and fail-closed recovery protect
  filesystem state.
- Capacity uses observed allocated size with logical size as a fallback.
- Instance-wide TTL and TTI support opportunistic expiration and configurable
  access-date persistence.

### evidence and benchmarks

- 70 tests cover cache contracts, LRU behavior, concurrency, persistence,
  capacity, expiration, recovery, and failure handling.
- Filesystem metadata behavior is validated on macOS, Apple Simulators, Mac
  Catalyst, and an iPhone 15 Pro running iOS 26.5.2.
- Release benchmarks cover memory-cache operations, file-cache operations, and
  deterministic policy hit-rate comparisons.
- The policy benchmark includes a bundled smoke trace and supports external CSV
  and libCacheSim `oracleGeneral` traces.

## requirements

- Swift 6
- iOS 16 or later
- macOS 13 or later
- Mac Catalyst 16 or later
- tvOS 16 or later
- watchOS 9 or later
- visionOS 1 or later
