# latte 0.2.0

Latte 0.2.0 adds opt-in, process-local statistics to both cache
implementations while preserving the existing cache protocols, initializer
selectors, and file format.

## highlights

### shared statistics snapshot

- Adds `CacheStatistics` with hit, miss, rejection, eviction, evicted-cost,
  and residency metrics.
- Adds synchronous and asynchronous statistics capability protocols without
  changing `Caching` or `AsyncCaching`.
- Keeps collection disabled by default and selected at construction time.
- Returns `nil` when disabled and an immediately available zero snapshot when
  enabled.
- Uses saturating counters and preserves meaningful hit-rate calculation at
  counter limits.

### memory cache statistics

- Collects request outcomes, rejected insertions, capacity evictions, evicted
  cost, and current residency.
- Owns statistics under the existing cache state lock.
- Preserves lock-outside destruction behavior for keys and values.

### file cache statistics

- Collects the same metric shape under the file cache's serial worker.
- Derives residency from the authoritative inventory and file cost model.
- Keeps statistics reads nonthrowing and free of file-system I/O.
- Starts each cache instance with a new statistics epoch while including
  recovered files in residency.
- Preserves lookup semantics across swallowed cleanup and touch failures.

### measurement and documentation

- Adds paired AB/BA benchmark modes for measuring statistics collection
  overhead.
- Keeps snapshot retrieval and correctness validation outside timed regions.
- Documents request, rejection, eviction, residency, lifecycle, and cost-unit
  semantics.

## compatibility

- Existing cache initializer selectors remain source compatible.
- Statistics are additive and disabled unless explicitly enabled.
- File layout, marker format, recovery behavior, and persisted cache data are
  unchanged.
- Statistics counters are process-local and are not persisted.
