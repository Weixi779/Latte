# latte 0.2.1

Latte 0.2.1 is a documentation-only patch release that makes the project
overview easier to scan and use.

## highlights

- Reorganizes the main README around features, installation, memory cache,
  file cache, statistics, composition, benchmarks, and technical references.
- Adds a complete Simplified Chinese README with the same information
  structure as the English document.
- Adds release, platform, Swift, Swift Package Manager, and license badges.
- Clarifies cache behavior, file-cache ownership, statistics lifecycle, and
  benchmark boundaries.

## compatibility

- No library source or public API changes.
- No file format, persistence, or runtime behavior changes.
- Fully compatible with applications using Latte 0.2.0.

## installation

```swift
dependencies: [
    .package(
        url: "https://github.com/Weixi779/Latte.git",
        from: "0.2.1"
    )
]
```
